# UI

One URL `/`. Shell + panels. Same features on desktop and phone. Clickable check: [`2d/`](../2d/). Record decisions here once we say "this is how it sticks."

## Flow

```
prologue (4 steps) → end of demo (restart)
```

The 2D starts directly in the prologue.

## Prologue

- Flow track segments; the prologue is livelihood, region, bell, origin.
- The eye ("whole scene") zooms out; the picture can be dragged. Step arrows and a keyboard left/right move between steps.
- Scroll edges fade softly; copy reveals first, choices follow one by one.
- Toast is a small confirmation or error only.
