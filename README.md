# Land of Machala

**A text RPG about how sure you can be.** Nobody lies out of malice, but everybody knows a slightly different story. Every fight, rumour and deal asks: *how much do you trust what you see?*

## Play

**[Open the demo in your browser](https://lowcash.github.io/land-of-machala/)** — no install, no build.

This public build is a **prologue demo**: tavern → four choices → name → morning. Deeper systems (combat, rumour case, map) live in the full prototype under `prototype/` for contributors who want to dig in.

Dialogue and UI copy in the game are in Czech.
